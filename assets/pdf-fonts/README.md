# Chinese PDF font

Unmodified NotoSansCJKsc-Regular.otf from the Noto project's official repository:
https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese

Distributed under the SIL Open Font License 1.1; the complete license and copyright are in OFL.txt.
This font is used only by the server-side PDF renderer. It does not replace the application's system UI fonts.
